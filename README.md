# Python Libraries & Machine Learning

A practical learning repository documenting my journey through Python programming, data science, machine learning, and deep learning. It contains structured Jupyter notebooks, hands-on implementations, and experiments covering essential Python libraries and machine learning frameworks.

## Overview 

This repository serves as a collection of practical implementations developed while learning and exploring Python libraries and machine learning technologies.

The focus is on understanding fundamental concepts through coding, experimentation, and implementation rather than relying solely on theoretical explanations.

The repository currently covers:

- **Data Analysis:** NumPy and Pandas
- **Data Visualization:** Matplotlib and Seaborn
- **Machine Learning:** Scikit-learn
- **Deep Learning:** TensorFlow and Keras
- **Pretrained Models:** TensorFlow Hub
- **Natural Language Processing:** Hugging Face Transformers

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/Sumaira-K/Python-Libraries.git
cd Python-Libraries
```

### Install Dependencies

For the data science and machine learning notebooks:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

For the deep learning and transformer notebooks:

```bash
pip install tensorflow tensorflow-hub transformers torch
```

### Launch Jupyter Notebook

```bash
jupyter notebook
```

Navigate to the relevant library folder and open the notebooks.

**Note:** Individual notebooks may require additional dependencies or pretrained model downloads.
