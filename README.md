# Python Libraries for Data Science

A structured learning repository covering essential Python libraries used in data analysis, visualization, and machine learning. The repository contains practical Jupyter notebooks, examples, and exercises developed while learning and applying these libraries.

## Overview

This repository documents hands-on learning with commonly used Python libraries for data science and machine learning.

Instead of only studying library documentation, the concepts are explored through practical examples and exercises to build familiarity with real-world Python data workflows.

The repository currently covers:

* NumPy
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn

Each library has its own section containing relevant notebooks and practical implementations.

## Libraries Covered

### NumPy

Focuses on numerical computing and working with arrays.

Topics include:

* Array creation and manipulation
* Array indexing and slicing
* Mathematical operations
* Statistical operations
* Broadcasting
* Working with multidimensional arrays

### Pandas

Focuses on data manipulation and analysis using Series and DataFrames.

Topics include:

* Series and DataFrames
* Data selection and filtering
* Data cleaning
* Handling missing values
* Sorting and grouping
* Data aggregation
* Reading and working with datasets

### Matplotlib

Focuses on creating and customizing data visualizations.

Topics include:

* Line plots
* Bar charts
* Scatter plots
* Histograms
* Subplots
* Labels and titles
* Grid customization
* Figure formatting

### Seaborn

Focuses on statistical data visualization and creating informative visualizations with less code.

Topics include:

* Distribution plots
* Count plots
* Box plots
* Scatter plots
* Heatmaps
* Categorical visualizations
* Statistical relationships

### Scikit-learn

Focuses on fundamental machine learning workflows using Python.

Topics include:

* Data preprocessing
* Train-test splitting
* Feature scaling
* Encoding categorical variables
* Model training
* Model evaluation
* Classification
* Regression
* Basic machine learning workflows

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/Sumaira-K/Python-Libraries.git
cd Python-Libraries
```

### Install Dependencies

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

### Launch Jupyter Notebook

```bash
jupyter notebook
```

Open the required library folder and run the notebooks to explore the examples and exercises.
